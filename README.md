# ⚽ יומן משחקי ברצלונה

יומן שמתעדכן לבד ומכיל את כל המשחקים של ברצלונה בלה ליגה, בליגת האלופות, בגביע המלך ובסופרקופה.
כל משחק כולל את המסגרת, המגרש, שורת הסבר על היריבה, ותזכורות יום לפני ושעה לפני.
אחרי המשחק התוצאה מתווספת לכותרת (✅ ניצחון / 🤝 תיקו / ❌ הפסד).

נוצר ע״י [עידן דיוה](https://www.linkedin.com/in/idan-diva/)

## התקנה חד-פעמית (כ-10 דקות)

### 1. העלאה ל-GitHub
1. נכנסים ל-github.com ונרשמים (חינם).
2. לוחצים על **+** למעלה ← **New repository**.
3. שם: `barca-calendar` ← מסמנים **Public** (גוגל יומן צריך גישה לקובץ) ← **Create repository**.
4. לוחצים על **uploading an existing file** וגוררים את כל הקבצים מהתיקייה הזאת, כולל התיקייה `.github`.
   אם התיקייה `.github` לא נגררת: **Add file ← Create new file**, בשם הקובץ כותבים `.github/workflows/update.yml` ומדביקים את התוכן שלו.
5. **Commit changes**.

### 2. הרצה ראשונה
1. בלשונית **Actions** ← אם מופיעה בקשה, לוחצים על **I understand… enable workflows**.
2. בוחרים **עדכון יומן ברצלונה** ← **Run workflow**.
3. אחרי כדקה יופיע בריפו קובץ חדש בשם `barca.ics`. מעכשיו הוא יתעדכן לבד כל 6 שעות.

### 3. קישור המנוי
הקישור (מחליפים את `USERNAME` בשם המשתמש שלכם ב-GitHub):
```
https://raw.githubusercontent.com/USERNAME/barca-calendar/main/barca.ics
```

### 4. הוספה ליומן, לכל אחד מכם
**גוגל יומן** (צריך לעשות את זה במחשב, לא באפליקציה):
calendar.google.com ← ליד **יומנים אחרים** לוחצים **+** ← **מכתובת URL** ← מדביקים את הקישור ← **הוספת יומן**.
היומן יופיע גם באפליקציה בטלפון.
> גוגל יומן לא קורא תזכורות מתוך יומנים שנרשמים אליהם בקישור. כדי לקבל אותן: בהגדרות היומן "משחקי ברצלונה" ← **התראות על אירועים** ← מוסיפים "יום אחד לפני" ו"שעה לפני".
> גוגל מרענן יומנים כאלה כל כמה שעות, כך ששינויים בשעות מופיעים באיחור קטן.

**אייפון / יומן של אפל:** הגדרות ← יומן ← חשבונות ← הוספת חשבון ← אחר ← **הוספת לוח שנה מנוי** ← מדביקים את הקישור. התזכורות יעבדו אוטומטית.

**Outlook:** הוספת יומן ← **הירשם מהאינטרנט** ← מדביקים את הקישור.

## התאמות
- **הסברים על יריבות:** בקובץ `teams.py`. כדי להוסיף קבוצה מוסיפים שורה. קבוצה שלא מופיעה שם תוצג בשם האנגלי שלה.
- **תזכורות:** בקובץ `barca_calendar.py`, בשורה עם `-P1D` (יום) ו-`-PT1H` (שעה).
- **מסגרות:** ב-`COMPETITIONS` שבקובץ `teams.py`.

הנתונים מגיעים מ-ESPN. כשהשעה של משחק עוד לא נקבעה, הוא מופיע כאירוע של יום שלם עם 🕒, ומתעדכן לבד כשהשעה נקבעת.
